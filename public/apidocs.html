API Referansı
Aerys — Kanal ve video analitik API'si
Base URL
https://yourdomain.com
Format

Tüm istekler application/json döner. Hata yanıtları { "detail": "..." } formatındadır.

Kimlik Doğrulama

Tüm /api/v1/ endpoint'lerine istek atmak için bir API anahtarı gereklidir. Anahtarı x-api-key header'ı ile gönderin.

HTTP Header
x-api-key: yte_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Örnek — cURL
bash
curl -X POST "https://yourdomain.com/api/v1/video/analyze" \
  -H "Content-Type: application/json" \
  -H "x-api-key: yte_YOUR_KEY" \
  -d '{"video_id": "dQw4w9WgXcQ"}'

POST /api/v1/channel/init
Bir YouTube kanalının meta verilerini (başlık, abone sayısı, açıklama, avatar) ve video listesini çeker. Sonuçlar 10 dakika cache'lenir.
İstek Gövdesi
AlanTipZorunluAçıklama
channel_urlstringEVETTam YouTube kanal URL'si. @handle, /c/ veya /channel/ formatı kabul edilir.
Örnek İstek
json
{
  "channel_url": "https://www.youtube.com/@MrBeast"
}
Örnek Yanıt
json
{
  "success": true,
  "channel_info": {
    "id": "UCX6OQ3DkcsbYNE6H8uQQuVA",
    "title": "MrBeast",
    "description": "...",
    "subscriber_count": "338.000.000 abone",
    "total_videos_count": 780,
    "avatar": "https://..."
  },
  "all_video_ids": ["abc123", "..."],
  "videos": [
    {
      "id": "abc123",
      "title": "Video Başlığı",
      "thumbnail": "https://i.ytimg.com/vi/abc123/hqdefault.jpg",
      "url": "https://www.youtube.com/watch?v=abc123"
    }
  ]
}
Dene
⚠ API anahtarınızı aşağıya girin. Dashboard → API Anahtarları bölümünden oluşturabilirsiniz.
POST /api/v1/channel/page-details
Verilen video ID listesi için izlenme, beğeni ve süre bilgilerini doldurur. En fazla 10 video işlenir.
İstek Gövdesi
AlanTipZorunluAçıklama
video_idsstring[]EVETVideo ID listesi. Max 10 adet. /channel/init'ten gelen all_video_ids'i kullanın.
Örnek İstek
json
{
  "video_ids": ["dQw4w9WgXcQ", "9bZkp7q19f0"]
}
Dene
POST /api/v1/video/analyze
Bir videonun izlenme, beğeni, yorum sayısını çeker ve engagement rate ile performans skoru hesaplar.
İstek Gövdesi
AlanTipZorunluAçıklama
video_idstringEVETYouTube video ID (URL'deki ?v= sonrası)
comment_limitintegerhayırŞu an kullanılmıyor, ileride eklenecek. Varsayılan: 100
Örnek Yanıt
json
{
  "success": true,
  "video_info": {
    "title": "Video Başlığı",
    "view_count": 1234567,
    "like_count": 45678,
    "total_youtube_comments": 3210,
    "duration_seconds": 213,
    "thumbnail": "https://i.ytimg.com/vi/.../maxresdefault.jpg",
    "analysis": {
      "engagement_rate": "%3.97",
      "channel_contribution_score": "Normal Katkı"
    }
  }
}
